# Discover China — Interactive Study Tour

A bilingual Italian / English editorial-style website presenting two 14-day study-tour routes in China.

## Current prototype
- Route A / Route B switch
- Interactive Leaflet map with numbered stops and a connecting route
- Click a map marker or stop card to open a destination detail panel
- Italian / English language switch
- Responsive desktop and mobile layout

## Important: sample content
The current markers are provisional examples (Beijing and Xi'an) used to demonstrate the map interaction. They are **not** the confirmed project itineraries. Replace the sample stop data in the JavaScript inside `index.html` with the actual destinations, dates, descriptions and coordinates before presenting the site as a final itinerary.

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub to publish the site. The public address should be:
   `https://bianca3363.github.io/discover-china-study-tour/`
